Diap. 3

ISO 9126 (1/3)

ISO 9126 es un estándar internacional para la evaluación de la calidad del software, y se
centra en definir un marco para medir la calidad en base a seis características
principales:

1. Funcionalidad
2. Fiabilidad
3. Usabilidad
4. Eficiencia
5. Mantenibilidad
6. Portabilidad

Facultad de Minas
Sede Medellín

Diap. 4

ISO 9126 (2/3)

Partes de la Norma

1. Parte 1 - Modelo de Calidad: Define un marco de trabajo para la calidad del software,

identificando características y subcaracterísticas.

2. Parte 2 - Métricas Externas: Evalúan la calidad del software desde la perspectiva del

usuario final.

3. Parte 3 - Métricas Internas: Evalúan la calidad del software desde la perspectiva del

desarrollador.

4. Parte 4 - Métricas de Calidad en Uso: Evalúan la calidad del software en su entorno

operativo real.

Diap. 5

ISO 9126 (3/3)

Nota: ISO 9126 fue reemplazado por la serie de normas ISO/IEC 25000 (también
conocida como SQuaRE), que actualiza y amplía los criterios de evaluación de calidad
del software.

Diap. 6

ISO 9126 - Funcionalidad (1/1)

Funcionalidad: Capacidad del software para proporcionar funciones que satisfagan
necesidades explícitas e implícitas.

Subcaracteristicas

Adecuación: El software debe cumplir con las funciones especificadas.

Exactitud: Capacidad del software para proporcionar resultados correctos.

Interoperabilidad: Capacidad del software para interactuar con otros sistemas.

Seguridad: Protección contra el acceso no autorizado.

Cumplimiento: Alineación con normas, leyes y reglamentos.

Facultad de Minas
Sede Medellín

Diap. 7

ISO 9126 - Fiabilidad (1/1)

Fiabilidad: Capacidad del software para mantener su nivel de rendimiento bajo
condiciones específicas.

Subcaracteristicas

Madurez: Frecuencia con la que fallan las funciones del software.

Recuperabilidad: Capacidad para restaurar su nivel de rendimiento tras un fallo.

Tolerancia a fallos: Capacidad del software para mantener un nivel de rendimiento
especificado en caso de defectos.

Facultad de Minas
Sede Medellín

Diap. 8

ISO 9126 - Usabilidad (1/1)

Usabilidad: Esfuerzo necesario para usar el software y la evaluación individual de dicho
uso.

Subcaracteristicas

Comprensibilidad: Facilidad con la que los usuarios entienden el funcionamiento
del software.

Aprendizaje: Facilidad para aprender a usar el software.

Operabilidad: Facilidad con la que los usuarios pueden operar el software.

Atractivo: Grado en que el software es atractivo para los usuarios.

Facultad de Minas
Sede Medellín

Diap. 9

ISO 9126 - Eficiencia (1/1)

Eficiencia: Relación entre el rendimiento del software y la cantidad de recursos
utilizados.

Subcaracteristicas

Comportamiento en el tiempo: Respuesta del software a las demandas temporales.

Utilización de recursos: Cantidad de recursos utilizados por el software en
relación a su rendimiento.

Facultad de Minas
Sede Medellín

Diap. 10

ISO 9126 - Mantenibilidad (1/1)

Mantenibilidad: Esfuerzo necesario para realizar modificaciones especificadas.

Subcaracteristicas

Facilidad de análisis: Capacidad de identificar las causas de fallos y modificarlas.

Estabilidad: Probabilidad de que el software no presente efectos colaterales
negativos tras cambios.

Facilidad de prueba: Grado en que se pueden realizar pruebas para verificar los
cambios en el software.

Facultad de Minas
Sede Medellín

Diap. 11

ISO 9126 - Portabilidad (1/1)

Portabilidad: Capacidad del software para ser transferido de un entorno a otro.

Subcaracteristicas

Adaptabilidad: Capacidad del software para ser adaptado a diferentes entornos.

Instalabilidad: Facilidad con la que el software puede ser instalado en diferentes
entornos.

Conformidad: Grado en que el software se ajusta a estándares y especificaciones.

Reemplazabilidad: Facilidad con la que un software puede reemplazar a otro
software específico en el mismo entorno.

Pasos para evaluar la calidad (1/2)

La evaluación de la calidad durante el ciclo de desarrollo se divide en los siguientes
pasos. El paso 1 debe realizarse durante la actividad de análisis de requisitos. Los
pasos 2 a 5 deben repetirse durante cada actividad definida en el ciclo de vida. Nota:
las actividades estan definidas en ISO 12207.

Facultad de Minas
Sede Medellín

Diap. 13

Pasos para evaluar la calidad (2/2)

Pasos para la evaluación:

1. Identificación de los requisitos de calidad
2. Especificación de la evaluación
3. Diseño de la evaluación
4. Ejecución de la evaluación
5. Retroalimentación a la organización

Facultad de Minas
Sede Medellín

Diap. 14

Paso 1: Identificación de los requisitos de calidad (1/4)

Para cada una de las características y subcaracterísticas de Calidad definidas en el
modelo de Calidad determine los pesos de las necesidades de los usuario por cada
categoría de la medida. (Calidad de uso, Calidad externa y Calidad interna). La
asignación de pesos relativos permitirá a los evaluadores centrar sus esfuerzos en las
subcaracterísticas más importantes.

Paso 4: Ejecución de la evaluación (1/1)

Este paso se aplica durante cada actividad del proceso de desarrollo. Ejecute el plan de
evaluación y complete la columna de la Tabla del paso 2. La serie de normas ISO/IEC
14598 debe utilizarse como guía para planificar y ejecutar el proceso de medición.

Sede Medellín

Diap. 28

Paso 5: Retroalimentación a la organización (1/1)

Este paso se aplica durante todas las actividades del proceso de desarrollo. Una vez
completadas todas las mediciones, incluya los resultados en la Tabla del paso 1 y
documente las conclusiones en un informe. Identifique también las áreas específicas en
las que es necesario mejorar la calidad para que el producto satisfaga las necesidades
del usuario.
